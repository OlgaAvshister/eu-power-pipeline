\# API response samples



Raw responses from the Energy-Charts API, captured for schema reference.



Endpoint: GET https://api.energy-charts.info/public\_power

Captured: 2026-08-19



\- `public\_power\_de\_2026-08-15\_1h.json` — Germany, 1 hour, 5 data points

\- `public\_power\_fr\_2026-08-15\_1h.json` — France, same hour, different set of production types

\- `public\_power\_de\_2026-08-19\_truncated.json` — Germany, full day requested, response silently truncated to 34 points
